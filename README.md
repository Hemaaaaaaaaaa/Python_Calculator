# Python GUI Calculator

A simple **Python Calculator** built using the **Tkinter** library for graphical user interfaces. This calculator can perform basic arithmetic operations like addition, subtraction, multiplication, and division, along with additional functions such as square root and trigonometric operations (sine, cosine, tangent).

## Features
- **Basic Arithmetic**: Addition, subtraction, multiplication, division
- **Square Root**: Calculates the square root of a number
- **Trigonometric Functions**: Calculates sine (`sin`), cosine (`cos`), and tangent (`tan`) of an angle (input in degrees)
- **Clear Display**: Resets the input field when the "C" button is pressed
- **Error Handling**: Displays an error message when invalid input is provided

## Requirements
- Python 3.x or higher
- Tkinter (comes pre-installed with Python)
